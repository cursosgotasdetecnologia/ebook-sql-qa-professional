## 🎯 Sobre o Ebook

Este não é mais um livro de SQL genérico. É um **manual de campo** para QAs que querem investigar bugs diretamente no banco de dados, validando dados, encontrando inconsistências e reportando evidências concretas.

**Diferencial:** 
- ✅ Foco 100% em PostgreSQL
- ✅ Banco de dados realista (e-commerce com bugs propositalmente inseridos)
- ✅ Queries nascem de problemas reais de investigação
- ✅ Mentalidade de "QA Investigador"

---

## 📋 Pré-requisitos

Antes de começar, você precisa ter instalado:

### 1. PostgreSQL (versão 15 ou 16). Mas se pretende usar com SUPABSE, tem de ser o mais recente.
- **Download:** https://www.postgresql.org/download/
- Durante a instalação, **anote a senha** do usuário `postgres`

### 2. DBeaver Community (GUI)
- **Download:** https://dbeaver.io/download/
- Versão Community é gratuita e suficiente

### 3. Git e GitHub
- **Git:** https://git-scm.com/
- **GitHub:** https://github.com (crie uma conta gratuita)
